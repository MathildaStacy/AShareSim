# 原型源文件

`../prototype.html` 是由这里的文件拼出来的单文件原型，直接用浏览器打开即可（不联网）。

| 文件 | 内容 |
| --- | --- |
| `core.js` | 规则、费用、行情模拟、撮合、清算（对应 `docs/TRADING_RULES.md` 的简化实现） |
| `ui-base.js` | 路由、浮层、K 线 / 分时 / 折线图、时钟 |
| `ui-market.js` | 自选、行情、个股、搜索 |
| `ui-trade.js` | 交易、下单、撤单、持仓、委托、交割单、银证转账 |
| `ui-learn.js` | 学习：路线图阶段 0/1/2/3/7、规则课、费用计算器、集合竞价演示、数据练习、账户分析、数据中心、模拟执行 |
| `ui-ai.js` | AI 助手：页面上下文、操作记录、对话列表与摘要、长期记忆、上下文查看页、服务配置 |
| `ui-me.js` | 我的、费率与交割单校准、原型控制台、启动 |
| `shell.html` | 页面骨架和样式 |
| `snapshot-2026-10-26.json` | 2026-10-26 11:30 从腾讯接口抓的快照、分时、日线 |

```bash
python3 build.py                                   # 生成 ../prototype.html
node rules-test.js snapshot-2026-10-26.json core.js # 费用 / 红利税 / 价格笼子 / 涨跌停自检
```

打开 `prototype.html#买入`、`#个股`、`#账户分析` 等可以直接跳到某个页面（名称见原型右侧控制台的「页面」列表）。
