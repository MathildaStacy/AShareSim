# M5 组合与调仓 / 数据中心

用户确认：优先每周按策略调仓、完成后复盘。模式：Operate。

## Direction contract

THESIS：一次调仓是一项有起点、有执行证据、有复盘结尾的周任务。首页先给下一步，历史和配置后置。

OWN-WORLD：延续交易页冷灰底、白色内容区、原生中文、等宽数字、买红卖蓝；状态用文字明确表达，复盘用既有学习色。手机日常室内阅读，继续现有浅色主题。

STORY：建策略并保留版本 → 输入完整账户目标 → 看逐笔阻塞与资金方案 → 一次确认 → 跟踪补单 → 写复盘并生成可对账报告。数据中心从证据入口进入，历史未知明确显示未知。

FIRST VIEWPORT：首页导航下是本周日期和下一步行动；已有任务直接继续，无任务给建立计划。连续周数作为小型进度说明，策略、往期报告在后。预检页先列现金需求和阻塞，再逐只比较当前与目标，底部提供确认。执行页先给成交状态，逐笔可打开委托/成交详情。

FORM：既有交易页的任务流程扩展；结构由确认的周度流程决定，code-led，未进行视觉世界替换。

FINISH：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## PM 决策

- 导入的是整个账户的目标；未列入持仓会生成清仓行，导入前和确认前都能看到。
- 不要求每周必须交易；无差额计划可以复盘，必须写原因。漏执行另记原因，不补连续周数。
- 策略版本冻结进计划。确认时授权一次买入补报与 14:50 撤销，不在后台自动改变目标数量。
- 资金不足时不依赖未成交卖单；先卖后买在 9:30 后按实有资金执行，无法买入的明示放弃。
- 影子账户遵循产品文档放到 M5 后半；本次主线为主账户执行闭环。
