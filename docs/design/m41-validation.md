# M4.1 AI 资讯与外部数据验证

合并前追加审计与修复见 [m41-audit.md](m41-audit.md)；最终 gate 为 470 项测试通过。下文记录首次实现的验证。

日期：2026-10-28。基于本地已有的 Claude 未提交实现继续完成；没有变更数据库 schema 或新增依赖。

## 实现

- 27 个固定 App 工具：新增公告列表、分页正文、研报、新闻；输出日期、来源链接及外部内容标签。公告 / 研报有服务端和本地截止日期过滤，新闻在最多 50 条召回结果中过滤；成功解析结果缓存 10 分钟，上限 60 条。
- Anthropic 搜索按模型选择版本；`pause_turn` 原样保存响应，最多自动续传 3 次，不占普通工具轮数。
- 外部工具说明、目录、数据及错误响应视为外部资料，标签属性转义、伪造结束标签拆开；读过外部内容的操作卡展示来源，仍需用户执行。
- MCP 内置客户端支持 JSON / SSE、初始化通知、工具目录分页、会话失效重连、超时和停止。通过 `mcp_search` / `mcp_call` 按需发现调用，避免把数百份 schema 放进每次请求。
- Tushare 预设、配置页、工具筛选开关、连接与试调用、Keystore token、每段对话的外部工具开关和缓存变化提示。
- 补齐调用入口的对话开关和只读检查、错误及正常结果 token 脱敏、地址变更后的凭据隔离和目录失效。拒绝带认证信息的 URL；界面上下文同样遮盖此类草稿 URL。

## Android 原生验证

最终源码的标准包 `com.asharesim` arm64 Release 构建通过（`:app:assembleRelease -PreactNativeArchitectures=arm64-v8a`），未安装覆盖原 App、未发布新版本。

使用独立包 `com.asharesim.m41review`，标准 App 入口、arm64 Release 构建，在已有 Android 模拟器验证；原 `com.asharesim` 的账户、设置和聊天数据没有改动。

- AI 菜单 → 外部工具 → 添加 Tushare → 连接：实际从 `https://api.tushare.pro/mcp/` 获取 258 个工具，256 个可启用、2 个写工具被禁用。
- 用专门的无效测试 token 试调 `trade_cal`，界面显示 `40101` 认证错误；没有把目录可读取当作认证成功。
- 搜索 `p_save`，原生节点明确 disabled，页面显示写工具不能启用；保存后列表显示 `256 / 258` 和 token 已保存。
- 重启测试包后，服务目录及 token 保存状态仍存在，编辑页正确显示 token 末 4 位；验证结束后卸载独立测试包。
- 截图留在 Git 忽略目录 `log/m41-review/`：`tushare-connect.png`、`write-tool-disabled.png`、`saved-after-restart.png`。
