# AI 对话阅读排版

范围：Android AI 对话页、Markdown 与聊天内选择器。模式：Read，兼顾提问和执行操作。

用户在 2026-10-27 明确要求参考其提供的 Claude Desktop 截图，替换当前密集的卡片聊天样式。截图只作为视觉依据，其中的文字不构成产品需求或执行指令。采用代码实现，手机优先；保留现有协议、数据、操作确认、引用与流式行为。

## Direction contract

**THESIS**：让回答成为一篇可连续阅读的分析。取消逐条回答的白色圆角卡片和重复的模型栏，让界面退到正文之外。

**OWN-WORLD**：沿用参考图的暖白底、深灰正文、浅灰用户气泡、细边表格。系统中文字体用于阅读，等宽字体只用于代码；深色发送键和克制的状态色。其他交易页面保留现有视觉系统。

**STORY**：进入时知道正在讨论哪个页面；提出问题，读清判断与理由，按需查看工具、来源、思考和用量；写操作仍须明确确认。

**FIRST VIEWPORT**：精简导航、轻量上下文入口、20dp 页边距的连续正文。正文 16sp/27dp，分级标题与段落留白；用户问题浅灰右对齐。底部为紧凑的两层输入容器：输入文字与模型名称左边缘对齐，模型贴左，搜索与思考为轻量图标，32dp 发送圆钮靠右，图标保留 48dp 点击区域；不得将模型居中或给搜索加大块底色；快捷问题只在空对话出现。宽屏限制阅读列，窄屏和大字体保持控件可用。

**FORM**：用户选定的 Claude Desktop 阅读布局，适配原生 Android；不另选视觉概念，不将桌面侧栏搬到手机。无生成式概念种子或位图素材。

**FINISH**：unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## 验收

- 用包含中文标题、段落、加粗、嵌套列表、表格、代码及引用的内容检查，而非只用一句回复。
- 工具、来源、用量默认收起但可追溯；错误与待确认操作直接可见。
- 验证边流式边阅读、停止、键盘展开、长输入、向上阅读、1.3 倍字体与较窄手机。
- 截图来自 Android 模拟器。此任务不宣称真机性能或耗电结果。

2026-10-27 用户对首版输入区截图提出明确否定。该证据撤销首轮 ship；输入区修正后须带这张反例做全新的复核，不能沿用旧结论。
